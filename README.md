# Бот ставок на площадке РАУ (СРО «Гарант»)

## Быстрый старт (панель с кнопками)
1. Один раз: `python launcher.py install` (на Linux `python3`).
2. Каждый раз: двойной клик по `ЗАПУСК.bat` (Windows) или `./start.sh` (Linux/macOS), либо `python launcher.py`.
   Откроется страница с кнопками: «Открыть браузер» -> войти в кабинет -> «Проверить вход» ->
   «Тренировка» -> «БОЕВОЙ режим». Список дел редактируется прямо на странице.
3. Окно консоли не закрывать. Панель доступна только на этом компьютере.
Ниже подробности и команды для отладки.

## Статус
Проверено тестами: расчёт минимальной ставки на 4 реальных протоколах, логика планировщика,
чтение targets.csv, режим «старт + шаг», лимиты. НЕ проверено на живом сайте: `rau_bot/browser.py`
(поиск дела, чтение ставок, форма, сертификат). Написано по скриншотам и записи экрана.
Поэтому по умолчанию бот в ТРЕНИРОВОЧНОМ режиме: форму заполняет, но не подписывает.

## Установка (один раз)
Нужен Python 3.11+ (python.org, на Windows галочка Add to PATH).
`install` сам создаёт виртуальное окружение `.venv` и ставит пакеты туда, а остальные команды launcher.py
запускает из него. Ошибка `externally-managed-environment` (Debian/Ubuntu) поэтому не возникает; не ставьте
пакеты через pip3 вручную. Если не создаётся .venv: `sudo apt install python3-venv python3-full`.
- Любая ОС: `python launcher.py install`
- Windows: `install.bat`    Linux/macOS: `./install.sh`

## Запуск (три способа, делают одно и то же)
| действие | любая ОС | Windows | Linux/macOS |
|---|---|---|---|
| браузер с портом | `python launcher.py browser` | `start_browser.bat` | `./start_browser.sh` |
| бот | `python launcher.py run` | `run.bat` | `./run.sh` |
Остальные команды (`check`, `selftest`, `dump`, `inspect`) тоже через `python launcher.py <команда>`.
Свой путь к браузеру: переменная окружения `RAU_BROWSER`.
`browser` открывает НОВОЕ окно с отдельным профилем `browser_profile/`: обычные вкладки не затрагиваются, закрывать
их не нужно, отладочный порт открывается всегда. В этом профиле войти через МЧД и поставить расширение/плагин для
ЭЦП нужно один раз, дальше всё сохраняется. Основной профиль: `python launcher.py browser --default-profile`
(все окна браузера предварительно закрыть; новые Chromium могут не открыть порт).

1. Запустить браузер (см. таблицу), войти в кабинет через МЧД (в новом окне).
2. `config.example.json` -> `config.json`; `targets.example.csv` -> `targets.csv`.
3. Проверки:
   - `python -m rau_bot check`: расчёт на протоколах из tests/data
   - `python -m rau_bot calc 3 3.1 7`: ставка по баллам конкурентов
   - `python -m rau_bot selftest`: связь с браузером и вход в кабинет
   - `python -m rau_bot dump <ИНН>`: сохранить страницу дела (нужна мне для настройки разбора)
   - `python -m rau_bot inspect <имя>`: снимок ТЕКУЩЕЙ вкладки (скриншот, текст, поля) в папку debug/
4. Тренировка: `python launcher.py run` (dry_run=true). Смотреть `journal.csv` и папку `debug/`.
5. Боевой режим: в config.json `"dry_run": false`.

## targets.csv
Заголовок: `inn;max_bid;initial;step;au1;au2;au_cap`, пустое поле = из config.json.
- предел ставки = минимум из max_bid, au_cap (лимит АУ на дело) и 805 (баллы СРО);
- «физики»: max_bid=5, initial=0.1, step=0.5 -> ставки по сетке 0,1 / 0,6 / 1,1 ... не выше предела;
- АУ: ФИО или ИНН, почта через «|».

## Как бот ставит (экономия баллов)
1. Сразу подаёт стартовую ставку (по умолчанию 0,01), чтобы быть участником.
2. За N минут до конца (N = число дел × `window_s_per_case`, но не меньше `final_window_min` и не больше `max_window_min`; 45 дел и больше → 15 минут (потолок), 20 дел → 7, 3 дела → 3 (минимум)) опрашивает дело каждые `poll_fast_s` (15) секунд.
3. Расчётную ставку подаёт только за `bid_not_before_s` (180) секунд до конца, затем повышает,
   только если конкуренты перебили. Понижать не пытается.
4. Не подаёт, если нужная ставка выше предела или выше «Доступных баллов» АУ в форме.

## Что проверить в понедельник (по порядку)
1. `selftest`, затем `dump <ИНН>` на деле 19.10: прислать мне debug/ и dump_*.txt/.html.
2. Тренировка на 1-2 делах: ставка в форме совпадает с расчётом, нужные АУ выбраны, «Доступные баллы» прочитаны.
3. Боевая подача на одном деле с минимальной ставкой: статус «Принято»?

## Допущения
- Новая заявка выше прежней заменяет её; ниже: площадка игнорирует или берёт последнюю: не проверено.
- Площадка сравнивает с округлённым или точным средним: неизвестно, ставка безопасна при обоих.
- Время окончания по Москве.

## Параллельная работа (несколько вкладок)

В `config.json` параметр `"workers"`: сколько вкладок работает одновременно (по умолчанию 1 — по очереди, как раньше).
При `workers` больше 1 бот открывает дополнительные вкладки в том же браузере (вход в кабинет общий), раздаёт дела
по кругу и каждая вкладка ведёт свои дела сама. Окно повышений считается по числу дел каждой вкладки.
Рекомендуется сначала проверить в режиме «Тренировка» с `"workers": 3`, и только потом включать боевой режим.
